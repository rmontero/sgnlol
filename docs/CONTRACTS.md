# Implementation contracts
Python 3.11+, FastAPI, Pydantic 2, SQLite durable queue, YAML hot-reloaded config. No UI. No GitHub writes. Environment secrets only. All times UTC epoch seconds.

triage/models.py: Event(BaseModel): id:str, org_id:str, source:Literal['github','slack'], kind:str, subject_key:str (PR URL or Slack thread key), repo:str|None=None, actor:str='', text:str='', url:str='', received_at:float (time.time default), metadata:dict default {}. Score(BaseModel): score:float 0..1, rationale:str, summary:str, input_tokens:int=0, output_tokens:int=0, fallback:bool=False. Route(BaseModel): recipient:str, threshold:float 0..1.
triage/config.py: Settings dataclass from_env(): database_path, config_path, github_webhook_secret, slack_signing_secret, slack_bot_token, slack_bot_user_id, openai_api_key, model ('gpt-4.1-mini'), batch_window_seconds (10), max_attempts (3), scoring_timeout_seconds (20), fail_safe ('forward'). load_config(path)->AppConfig; AppConfig.orgs:list[OrgConfig]. OrgConfig: id, github_org, slack_team_id, type startup|enterprise, recipient optional, threshold default .7, repos:dict[str,RepoConfig], slack_channels:list[str]. RepoConfig: recipients:list[str], threshold:float|None. Unknown orgs/repos/channels denied. Config refreshed per webhook/job.
triage/routing.py: resolve_routes(event:Event, config:AppConfig)->list[Route]. Startup uses configured recipient only for allowlisted repo/channel; enterprise uses repo recipients; Slack enterprise events may use org recipient if configured.
triage/ingest.py: verify_github(body:bytes,signature:str,secret:str)->bool; verify_slack(body:bytes,timestamp:str,signature:str,secret:str,now:float|None=None)->bool; normalize_github(payload:dict,event_type:str,delivery_id:str,config:AppConfig)->Event|None; normalize_slack(payload:dict,config:AppConfig,bot_user_id:str)->Event|None. org ID resolved from trusted config matched to payload identity; strict configured repo/channel allowlist. source IDs namespaced.
triage/store.py: Store(path); enqueue(event)->bool (dedup); claim(now=None)->Event|None (lease); retry(event_id,error,delay)->None; dead_letter(event_id,error)->None; complete(event_id,score:Score,routes:list[Route],batch_window:float)->None atomic score+pending deliveries; due_batches(now=None)->list[dict] with keys id,org_id,recipient,subject_key,events:list[dict] (Event model_dump),scores:list[dict] (Score model_dump); mark_sent(batch_id,ts)->None; retry_batch(batch_id,error,delay)->None; unknown_batch(batch_id,error)->None; stats()->dict; filtered(limit=50)->list[dict]; close(). Store exposes attempt_count(event_id)->int. SQLite each method synchronous/fast; claim reclaims expired leases. Batches claimed as sending, interrupted sends become unknown, never blindly replay. Retry safe explicit Slack failures only. event IDs unique per org and source.
triage/scoring.py: Scorer(settings); async score(event)->Score. OpenAI Agents SDK structured output, no tools; input untrusted. Timeout handled by worker. No secret/event body logging.
triage/delivery.py: SlackDelivery(settings); async send(batch:dict)->str (Slack ts); DeliveryError(message,retryable=False,uncertain=False,retry_after=0). httpx transport; errors classify explicit 429 as retryable, network timeouts/5xx as uncertain; no blind retries of uncertain writes; disable mentions and link unfurls. async close().
triage/worker.py: Worker(store,settings,scorer,delivery); async tick()->None; async run(stop:asyncio.Event)->None. Retry scoring with bounded exponential backoff; after max attempts forward fallback Score(score=1,fallback=True) using configured routes or dead-letter if fail_safe=dead_letter. Filter routes by score >= threshold. Process due batches even if scoring fails. Store scores and filtering reasons.
triage/app.py: create_app(settings=None,store=None,scorer=None,delivery=None,run_worker=True)->FastAPI; app=create_app(); POST /webhooks/github; POST /webhooks/slack; GET /healthz. Signature before JSON; Slack signed challenge; fast ack after durable enqueue. startup worker and orderly shutdown. max body 1MB.
